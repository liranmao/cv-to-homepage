# Template provenance

Website design and base styles are adapted from [Liran Mao's homepage](https://github.com/liranmao/liranmao.github.io), commit `16700beda5662b6e24896306a871a40843488761` (read on 2026-10-04).

The original site builds on [Minimal Light by Yaoyao Liu](https://github.com/yaoyao-liu/minimal-light), which credits [pages-themes/minimal](https://github.com/pages-themes/minimal), [orderedlist/minimal](https://github.com/orderedlist/minimal), and [al-folio](https://github.com/alshedivat/al-folio).

The source repository's CC0 1.0 Universal license is retained in `LICENSE`. This repository also distributes its new helper scripts and skill instructions under CC0. This does not grant rights in users' CVs, portraits, university marks, or publication figures.

Retained: sidebar/content proportions, navy navigation, serif typography, dark-mode palette, publication styles, and the subtle moving-particle design. Adapted: static Python renderer replaces Jekyll; accessible mobile navigation; safe text rendering; local canvas animation; text links replace third-party icon fonts; no analytics. Original personal content, photographs, CV, paper figures, CNAME and Git history are not distributed.
